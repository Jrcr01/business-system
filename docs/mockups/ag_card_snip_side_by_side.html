3 · Smaller things the check found

  1. Say what a column added up to. Today the line under the picture says only "Filled from the box.", so you cannot see which figures were read. It will list them with the total, as in the panel above.
  2. Commas in the filled figure. A snipped figure shows as "418537.11"; it will show "418,537.11" like the rest.
  3. "Next snip goes to: …" above the picture, so the box you picked is plain without looking back at the form; before a box is picked it reads "Click a box in the form first".
  4. Old typed figures. The figures you typed are kept while you move around the page; they are also cleared when you pick a different card, so one card's figures never land on another's statement.
