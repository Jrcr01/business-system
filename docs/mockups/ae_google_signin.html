What setting it up takes (about 20 minutes, your dashboards, I guide)

  1. Google Cloud Console (the project you already have): an OAuth consent screen named "Slick's Tire Supply ERP" with the logo; an OAuth client of type Web, its redirect address https://<team>.cloudflareaccess.com/cdn-cgi/access/callback. Copy the Client ID and secret.
  2. Cloudflare Zero Trust → Settings → Authentication → Add new → Google: paste the two values, Test.
  3. Zero Trust → Access → Applications → the ERP app → Login methods: tick Google, untick One-time PIN (or keep both), turn on Instant Auth.
  4. Nothing changes in the ERP code. The policy (the allow list) stays as it is; the "ERP open pages" bypass for /approve/ and /s/ stays.
  5. Test in an incognito window with your Gmail, then tell the family: "next time, just pick your Google account".
