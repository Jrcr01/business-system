How it behaves with a scanner:
  • The box keeps the focus — point, pull the trigger, the line appears. A sound and a green flash on each accepted scan.
  • Scanning the same tire again adds 1 to its line.
  • The Enter a scanner sends never saves the slip: only Done does.
  • A barcode the system does not know yet (the maker's own) asks once which item it is, then remembers it — as on Receive.
  • Goods in are already covered: receiving on the DR writes the stock, and labels print there.
Works with:
  • a wireless 2D handheld (Bluetooth or USB-dongle, ₱1,500–4,000 class) on the phone or the counter PC;
  • an Android scanner (Sunmi / Urovo class) running this very page — the "app on a scanner", nothing to install;
  • the phone camera, which costs nothing.
